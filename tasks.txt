1. Refactor Garbage Collector
Remove global g_gc

Encapsulate GC state in a dedicated context or as a member of your main shell struct.

Update every gc_malloc, gc_strdup, etc., to take that context pointer instead of relying on a global.

API cleanup

Ensure initialization and cleanup happen strictly around each command loop iteration.

Add error handling if GC allocation fails.

2. Refactor echo Built-in
Handle all quoting and expansions exactly as Bash does (including -n, $VAR, backslashes).

Don’t reimplement parsing—leverage your tokenizer/expander so echo just prints the already-expanded argv.

Normalize edge cases

echo -e (if supported)

Empty args, multiple spaces, printing literal -n when appropriate.

3. Unify Your Core Structs
Design a single t_shell or t_context that “inherits” all sub-structures:

env array

GC context

Last exit code, signal handlers, etc.

Embed or point to your AST, tokenizer state, I/O redirection structs, etc.

Pass only this one struct around to every function—no more sprawling parameter lists.

4. Audit & Fix Memory Leaks
Run through every code path with Valgrind.

Pay special attention to:

Token lists freed twice vs. never freed

Environment arrays on export/unset

Here-doc temporary buffers and file descriptors

Update cleanup routines to reliably tear down per-command data; reserve long-lived allocations (like shell context) for program exit.

5. Implement Here-Doc Support
Parser changes: recognize << delimiters and capture the delimiter word.

Execution changes:

Read lines from STDIN until the delimiter is seen.

Write them into a temporary FD or buffer.

Hook that FD into the command’s stdin before forking.

Edge-cases: quoting in the delimiter, signal handling (Ctrl-C), cleaning up temp files.
